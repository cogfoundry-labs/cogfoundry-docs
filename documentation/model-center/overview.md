This section covers using CogFoundry as a model API: one key, one base URL, and every frontier model behind OpenAI, Anthropic, and Google compatible endpoints. It answers three questions — how to authenticate, which model slug to send, and how usage is billed.

The rest of the site documents a different product. **LoomLoom** is the AI work compiler and runtime — templates, workbooks, runs, and SkillBots — and its documentation stays under its own tab. If what you need is a repeatable multi-step workflow rather than a single model call, start there instead.

Access to models requires a CogFoundry account and an API key from the [console](https://console.cogfoundry.ai/api-keys). Model availability, context windows, and prices are published on the [model list](https://cogfoundry.ai/en/models/) and can change over time, so treat that page as the source of truth rather than any table copied elsewhere.
